Weather Data Analytics Pipeline

📌 Project Overview

This project presents a simple data pipeline architecture for weather data.

The purpose of the project is not to build the complete pipeline, but to understand how data moves through different stages:

Source → Ingestion → Processing → Storage → Consumer

The architecture is designed using the ideas of logical data pipeline architecture and then mapped to practical technologies.

🎯 Objective

The main objective is to design a simple and understandable data pipeline that can:

Collect weather data from a public API

Bring the data into the pipeline

Clean and transform the data

Store the processed data

Make the data available for analysis and visualization

🌦️ Selected Data Source

Weather API

The selected source is a Weather API.

The API can provide information such as:

Temperature

Feels-like temperature

Humidity

Wind speed

Weather condition

Location

Timestamp

The collected information can be stored over time to support historical weather analysis.
